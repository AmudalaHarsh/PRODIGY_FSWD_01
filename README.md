# 🔐 Secure User Authentication System

---

## 📌 Overview

The **Secure User Authentication System** is a web application built using Spring Boot and Thymeleaf that provides secure user authentication and management.
It focuses on secure authentication and role-based authorization, ensuring users can only access resources permitted to their assigned roles through a clean and responsive interface.

---

## ✨ Features

✔️ User Registration
✔️ Secure Login & Logout
✔️ Role-Based Authentication
✔️ Admin & User Dashboard Access
✔️ Password Encryption (BCrypt)
✔️ Form Validation
✔️ Session Management
✔️ Protected Routes (Authentication required)

---

## 🔑 Roles & Access

* **ADMIN** → Access to admin pages
* **USER** → Access to user pages
